# 拆快递 · Unboxing Tycoon 📦

一个**拆快递主题的增量放置养成游戏**。你是国外一座废弃快递收容站里**脾气暴躁的看守老哥**，某天彻底暴走，开始疯狂拆快递——从徒手硬抠到黑洞吸拆，越拆越快、越拆越爽、越拆越离谱。

> 设计文档见 [DESIGN.md](./DESIGN.md)，技术架构见 [ARCHITECTURE.md](./ARCHITECTURE.md)。

## 玩法一览

- **拆**：按住工作台疯狂拆包，连击越高倍率越高、老哥越狂暴、骂得越凶。
- **掉落**：拆出未知物品——可卖品 / 材料 / 收藏品 / **暴躁老哥语录**，五档稀有度（普通→离谱）。
- **养成**：卖钱 → 升级工具与拆解力度 → 自动拆包工 → 流水线批量拆 → 全自动物流帝国。
- **语录**：收集并装备暴躁金句吃加成（🗯️ 面板）。
- **图鉴 / 成就 / 进货批次 / 离线收益 / 转生**：长线目标一应俱全。

## 本地运行

```bash
npm install
npm run dev        # 开发模式，浏览器打开提示的地址
```

## 其他命令

```bash
npm run build      # 类型检查 + 生产构建（输出 dist/）
npm run preview    # 预览生产构建
npm test           # 运行单元/集成测试（Vitest）
```

## 技术栈

React 18 + Vite + TypeScript + Zustand。零美术资源：全部用 emoji + CSS 实现，音效用 Web Audio 合成。
存档落 localStorage，含离线收益结算。
