# 美术资源清单与替换规格

本文件是本轮美术替换的固定清单。目标是把现有 emoji/模板感资源替换为符合《拆快递》黑色幽默、暴躁拆包、荒诞工业风调性的游戏美术资源。除展示层必要接入外，不修改掉落、数值、存档、结算等游戏逻辑。

## 全局规格

- 图标资源：`public/game-art/icons/*.png`，由 GPT image 生成源图后裁切/缩放得到，必须表达具体物体本身，不再只用通用盒子、抽象符号或 emoji 感模板。
- 场景背景：`public/game-art/backgrounds/*.png`，阶段背景随升级变化；远征现场必须有专属背景。
- 角色立绘：`public/game-art/characters/*.png` 和卖家头像 PNG，必须按角色身份、对白情绪和物品语境绘制，不使用同一张泛用头像糊过去。
- UI 皮肤：`public/game-art/ui/*.png` 与 CSS 展示层，使用 GPT Image 生成的位图面板、按钮、卡片槽、列表行、导航条、进度条和对白牌，整体改为工业游戏面板质感，避免网页卡片感。
- 禁止项：`public/game-art` 下不得存在 `.svg`；不得使用程序性绘图产出最终美术资源。
- 接入校验：所有在 `src/data` 中可见的美术对象必须能通过 `GameIcon` 或场景背景映射拿到资源文件，构建和测试必须跑通。
